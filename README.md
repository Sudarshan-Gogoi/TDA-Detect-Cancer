# TDAcancer-detect

**Topological Data Analysis and machine-learning framework for blood-biomarker-based multi-cancer detection, tissue-of-origin localization, and biomarker identification.**

This repository contains the Jupyter Notebook implementation accompanying the paper:

> **TDAcancer-detect: Integrating Topological Data Analysis and Machine Learning for Blood-Biomarker Based Multi-Cancer Detection and Biomarker Identification**

The repository contains two clinical datasets and two Jupyter notebooks. The `TDAcancer-detect.ipynb` notebook presents the main implementation and demonstration of the TDAcancer-detect model using Dataset 2, along with stability analyses and other associated analytical modules. The `Dataset_1_Analysis_and_Implementation.ipynb` notebook contains selected model implementations and analyses performed using Dataset 1. Together, the notebooks provide the code accompanying the study, including optimized biomarker selection, threshold-based cancer detection, tissue-of-origin localization, baseline comparisons, ROC analysis, and robustness/stability assessments.

> **Research-use notice:** This is a research implementation, not a clinically validated diagnostic system. Outputs should not be used to make individual medical decisions. The two clinical workbooks listed below are included in this repository for the purposes and under the conditions stated by the data providers. Users are responsible for complying with the original data providers' access conditions, licenses, and data-use agreements, and for protecting patient confidentiality.

## 2. Framework overview

TDAcancer-detect represents the relationships among selected blood biomarkers using patient-influenced correlation structures and persistent homology.

For an individual under evaluation, the individual's biomarker measurements are combined with a fixed group of 59 healthy reference individuals. After log transformation, a Pearson correlation matrix \(C\) is calculated across the selected biomarkers. The correlation matrix is converted to the nonnegative dissimilarity matrix

\[
D_{ij}=1-|C_{ij}|.
\]

The matrix is symmetric and has a zero diagonal after numerical cleanup. It is treated as a **dissimilarity matrix**; the implementation does not assume that it satisfies the triangle inequality. A Vietoris–Rips filtration is constructed from this matrix, and persistent homology is computed using GUDHI.

The resulting persistence diagrams are summarized using topological statistics, which are subsequently used for biomarker-panel selection, cancer detection, and tissue-of-origin localization.

### Main analytical components

1. **Topological feature extraction:** patient-level correlation/dissimilarity construction, Vietoris–Rips filtration, and 0D/1D persistent-homology summaries.
2. **Optimized Biomarker Selection (OBS):** four-stage constrained search over candidate biomarker panels.
3. **TDAcancer-detect-1:** binary cancer-versus-normal detection using two topological detection scores and an OR-based threshold rule.
4. **TDAcancer-detect-2:** one-vs-rest tissue-of-origin localization using three-biomarker combinations among patients correctly classified as cancer-positive by the detection stage.
5. **Baseline comparison:** Mahalanobis-distance, logistic-regression, and support-vector-machine (SVM) models.
6. **ROC comparison:** combined ROC analysis of TDAcancer-detect and the baseline models.
7. **Stability and supplementary analyses:** alternative reference-cohort configurations, repeated random partitions, panel-size investigations, and regression-predictor multicollinearity assessment.

## 4. Dataset 2 demonstration partition

In the supplied Dataset 2 demonstration configuration, the first 59 normal patients in the original workbook order are retained as the fixed Reference group. These patients are excluded from the subsequent calibration and test partitions.

After reserving the 59 reference patients:

| Patient group | Regression Fit Calibration 1 | Calibration 2 | Test |
|---|---:|---:|---:|
| Remaining normal patients | 15% | 50% | 35% |
| Cancer patients, within each cancer cohort | 0% | 50% | 50% |

The functional roles are:

- **Reference:** provides the fixed healthy cohort combined with each evaluated patient for patient-influenced correlation construction.
- **Regression Fit Calibration 1:** contains normal patients only; used to fit the regression model and estimate the healthy reference coordinates for Distance %(1).
- **Calibration 2:** used for biomarker-panel evaluation and threshold selection.
- **Test:** held out for final evaluation after panel and threshold selection.

The notebook's other stability and supplementary sections may use different partition configurations. Always consult the settings and explanatory comments in the specific section being run; do not assume that every analysis uses the demonstration partition above.

## 5. Topological features and cancer-detection scores

### Topological features

The detection workflow calculates persistence-based summaries, including:

- `0-Dim Hole Min Life Range`
- `0-Dim Hole Max Life Range`
- `Median_Death_0D`
- `Std_Death_0D`
- `Avg_Death_0D`
- `Average Birth (1D)`
- `Average Death (1D)`

The OBS implementation uses four 0D features as predictors in the linear regression model:

- `0-Dim Hole Min Life Range`
- `0-Dim Hole Max Life Range`
- `Median_Death_0D`
- `Std_Death_0D`

The exact features exported or used by a module can differ; refer to that module's code and the paper's Methods section.

### Regression Difference Percentage

A linear regression model is fitted using the normal patients in Regression Fit Calibration 1. It predicts the observed `Average Death (0D)` from the four 0D predictors. The Regression Difference Percentage is calculated as

\[
\mathrm{RDP}_i =
\left|\frac{A_i-\widehat{A}_i}{A_i}\right|\times 100,
\]

where \(A_i\) is the observed Average Death (0D) and \(\widehat{A}_i\) is its regression-predicted value.

### Distance %(1)

The two coordinates `Average Birth (1D)` and `Average Death (1D)` are compared with the corresponding mean coordinates calculated from the Calibration 1 normal patients. Their scaled Euclidean distance is used as Distance %(1).

### Binary decision rule

The two scores are combined using the OR rule:

\[
\text{Cancer-positive if }
\mathrm{RDP}_i>k_1
\quad\text{OR}\quad
\mathrm{Distance}\%(1)_i>k_2.
\]

Otherwise, the patient is classified as cancer-negative. The thresholds are selected using calibration data according to the constraints and optimization criteria configured in the relevant module.

## 6. Optimized Biomarker Selection (OBS)

The OBS module searches for biomarker panels using a four-stage constrained search:

1. **Balanced and diverse exploration:** samples panels while encouraging balanced biomarker representation and limiting overlap.
2. **Sensitivity-guided search:** uses biomarker recurrence in high-performing feasible panels to guide subsequent sampling.
3. **Recurrence-informed balanced exploration:** explores panels from a restricted pool of frequently recurring biomarkers.
4. **Local refinement:** explores one-biomarker substitutions around promising panels.

For the Dataset 2 demonstration configuration shown in the notebook, the principal settings include:

| Setting | Demonstration value |
|---|---:|
| Fixed Reference group | 59 normal patients |
| Normal Calibration 1 fraction, after Reference removal | 15% |
| Normal Calibration 2 fraction, after Reference removal | 50% |
| Cancer Calibration 2 fraction | 50% |
| Panel size | 8 biomarkers |
| Total unique panels | 3,000 |
| Random seed for panel search | 20261017 |
| Pooled Calibration 1 + Calibration 2 normal specificity requirement | Strictly greater than 99% |
| Maximum threshold candidates per score | 80 |
| Fixed numeric threshold bounds | None |

The 3,000-panel search budget is allocated as follows:

| Search stage | Panels | Budget |
|---|---:|---:|
| Stage 1: balanced and diverse exploration | 1,200 | 40% |
| Stage 2: sensitivity-guided search | 900 | 30% |
| Stage 3: recurrence-informed balanced exploration | 600 | 20% |
| Stage 4: local refinement | 300 | 10% |
| **Total** | **3,000** | **100%** |

For each panel, the regression model and Distance %(1) reference coordinates are estimated from Calibration 1 normal patients. Threshold candidates are evaluated using calibration data. Feasible panels must satisfy the pooled normal-specificity constraint across Calibration 1 and Calibration 2. The primary ranking objective is Calibration 2 macro-sensitivity across the cancer cohorts, with overall cancer sensitivity and pooled specificity used as tie-breakers. The held-out Test partition is reserved for final evaluation.

The notebook includes additional panel-size and repeated-split investigations. Their settings are not necessarily identical to the primary Dataset 2 demonstration.

## 7. TDAcancer-detect-1: binary cancer detection

The TDAcancer-detect-1 section applies the selected biomarker panel and optimizes the \(k_1\) and \(k_2\) thresholds under the specificity requirements specified in its own USER SETTINGS section.

The procedure:

1. Uses the fixed Reference group for patient-level TDA feature construction.
2. Fits the regression model and calculates healthy reference coordinates using Calibration 1 normal patients.
3. Selects thresholds using calibration data and the OR-based detection rule.
4. Applies the locked panel, regression model, reference coordinates, and thresholds to the held-out Test partition.
5. Reports overall and cohort-specific performance, and ROC-related outputs where configured.

**Important:** OBS and TDAcancer-detect-1 are distinct procedures. OBS searches candidate biomarker panels under its pooled specificity constraint. TDAcancer-detect-1 operates on a selected/fixed panel and has its own threshold-selection settings. Read the parameter values in the relevant code section rather than assuming that the constraints or threshold bounds are interchangeable.

## 8. TDAcancer-detect-2: tissue-of-origin localization

The localization module performs one-vs-rest classification for each target cancer type among patients correctly classified as cancer-positive (true positives) by the first-stage detection model.

The procedure described in the notebook is:

1. Retain eligible detection-Test cancer true positives and healthy true negatives.
2. Within each cancer cohort, partition eligible cancer true positives into Localization Calibration 1 (10%), Localization Calibration 2 (55%), and localization Test (35%).
3. Select 10% of eligible healthy true negatives for Localization Calibration 1 to construct the normal reference centroid. Other healthy true negatives are not used for localization evaluation.
4. Exclude cancer false negatives and healthy false positives from localization.
5. Generate all unique three-biomarker combinations from the configured candidate biomarker panel.
6. Extract the localization TDA features and calculate Distance %(3) relative to the normal reference centroid.
7. Tune the target-specific threshold and select the three-biomarker combination using Localization Calibration 2.
8. Evaluate the selected combination and locked threshold on the held-out localization Test subset.
9. Repeat the procedure across the configured random splits and summarize performance and biomarker recurrence.

For each target cancer type, that cohort is the positive class and the other eligible cancer cohorts form the negative class. Consequently, localization performance is conditional on successful first-stage detection; it is not an evaluation over all patients in the original detection Test set.

## 9. Baseline models and ROC comparison

The notebook includes three binary detection baselines:

- **Mahalanobis distance:** fits a healthy-reference distribution and selects an operating threshold using Calibration 2 normal patients under the configured specificity constraint.
- **Logistic regression:** uses the existing patient split, calibration-based threshold selection, and a final fit before Test evaluation.
- **Support-vector machine (SVM):** uses a standardized RBF-kernel SVM and calibration-based threshold selection before Test evaluation.

The combined ROC module reads previously saved continuous ROC coordinates and patient-level Test predictions. It checks that the methods use the same Test patient IDs and labels before generating a combined comparison. It does not retrain the models or recalibrate thresholds.

Run the baseline modules and save their expected outputs before running the combined ROC comparison. The filenames and worksheet names are specified in the ROC module's USER SETTINGS section.

## 14. Reproducibility and methodological safeguards

- The fixed Reference group is selected according to the source-row ordering specified in the relevant module.
- Randomized partitions and panel searches use explicit random seeds in the supplied configuration.
- Regression fitting and healthy reference-coordinate estimation use Calibration 1 normal patients.
- Panel and threshold selection use calibration data, not the held-out Test partition.
- The selected panel, fitted regression model, reference coordinates, and thresholds are held fixed for the corresponding Test evaluation.
- The localization analysis is conditional on the first-stage detection result and uses separate localization calibration and Test subsets.
- The matrix \(D=1-|C|\) is a dissimilarity matrix; the code does not claim it is a metric satisfying the triangle inequality.
- Different supplementary modules may use different split designs and random seeds. Report the configuration used for each analysis.

For a strict reproduction, preserve the input workbook, row ordering, biomarker-column names, random seeds, package versions, and all relevant settings. A different row order can change which normal patients are selected for a deterministic first-59 Reference group.
